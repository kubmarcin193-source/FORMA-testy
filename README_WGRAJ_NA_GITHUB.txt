FORMA PRO PWA v17.3

WDROŻENIE NA GITHUB PAGES
1. Rozpakuj ZIP.
2. Usuń stare pliki aplikacji z repozytorium albo nadpisz je wszystkimi plikami z tej paczki.
3. Wgraj pliki bez dodatkowego folderu — index.html ma leżeć bezpośrednio w katalogu publikowanym przez GitHub Pages.
4. Zatwierdź zmiany i poczekaj na zakończenie wdrożenia.
5. Otwórz WERSJA.txt na stronie. Powinien pokazać wersję v17.3.
6. Po aktualizacji zamknij aplikację całkowicie i uruchom ją ponownie.

PIERWSZE URUCHOMIENIE I HASŁO
- W publicznych plikach nie ma gotowego hasła ani weryfikatora konkretnego hasła.
- Przy pierwszym uruchomieniu na danej przeglądarce ustaw własne hasło.
- Hasło nie jest zapisywane. Losowa sól i weryfikator PBKDF2 są tworzone dopiero lokalnie w przeglądarce.
- Każde nowe urządzenie lub przeglądarka wymaga osobnego ustawienia hasła.
- Telefon po pierwszym uruchomieniu zostaje zapamiętany.
- Komputer wymaga hasła po ponownym uruchomieniu i blokuje aplikację po 5 minutach bezczynności.

CENTRALNE ZDJĘCIA ĆWICZEŃ
- Zdjęcie dodane do ćwiczenia w bibliotece jest źródłem nadrzędnym.
- Wszystkie ćwiczenia o tej samej nazwie automatycznie pokazują to samo zdjęcie w każdym zestawie.
- Wielkość liter i dodatkowe spacje w nazwie nie wpływają na dopasowanie.

FORMA PRO STUDIO
1. W aplikacji wyeksportuj ćwiczenia, zestawy i zdjęcia.
2. Otwórz Forma-PRO-Studio.html.
3. Zaimportuj plik JSON.
4. Dodaj zdjęcie jeden raz do właściwego ćwiczenia w bibliotece.
5. Wyeksportuj projekt i zaimportuj go z powrotem do Forma PRO.
